My macOS (Apple Silicon) shell setup, managed with [chezmoi](https://www.chezmoi.io/).

- **Shell:** zsh with a clean, XDG-style layout, so everything lives in `~/.config/zsh` and only `~/.zshenv` sits in `~`
- **Plugins:** [antidote](https://antidote.sh/) (no Oh My Zsh framework, only selected OMZ plugins)
- **Prompt:** [Starship](https://starship.rs/)
- **Secrets:** macOS Keychain, read when needed. **No secrets are stored in this repo.**

---

## Quick start (new Mac)

```sh
# 1. Homebrew (if missing)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. chezmoi + apply dotfiles (also runs `brew bundle` from the Brewfile)
brew install chezmoi
chezmoi init --apply git@github.com:<you>/dotfiles.git

# 3. Start a fresh login shell (the first run clones plugins)
exec zsh -l
```

Then:

1. Re-add secrets to the Keychain (see [Secrets](#secrets)).
2. Optionally create `~/.config/zsh/local.zsh` and `local.zprofile` for settings specific to this Mac.
3. Keep your old history: `mv ~/.zsh_history ~/.local/state/zsh/history`, if the file exists.

## Repository layout

chezmoi source names are converted when applied: `dot_` becomes `.`.

```
.
├── README.md                       # this file (ignored by chezmoi)
├── .chezmoiignore
├── Brewfile                        # Homebrew packages (ignored by chezmoi, used by the script below)
├── run_onchange_brew.sh.tmpl       # re-runs `brew bundle` when the Brewfile changes
├── dot_zshenv                      # → ~/.zshenv
└── dot_config/
    ├── starship.toml               # → ~/.config/starship.toml
    └── zsh/                        # → ~/.config/zsh  ($ZDOTDIR)
        ├── dot_zprofile            # → .zprofile
        ├── dot_zshrc               # → .zshrc
        ├── dot_zsh_plugins.txt     # → .zsh_plugins.txt
        └── conf.d/
            ├── 10-aliases.zsh
            ├── 20-functions.zsh
            ├── 30-tools.zsh
            └── 40-secrets.zsh
```

`.chezmoiignore` keeps repo-only files and private or generated files out of `~`:

```
README.md
Brewfile
.config/zsh/local.zsh
.config/zsh/local.zprofile
.config/zsh/.zsh_plugins.zsh
```

## How zsh loads

| File | Read by | What goes in it |
|---|---|---|
| `~/.zshenv` | every zsh, including scripts | `XDG_*`, `ZDOTDIR`, `EDITOR`, `typeset -U path fpath` |
| `.zprofile` | login shells (every new macOS terminal tab) | Homebrew and **all `PATH` changes** |
| `.zshrc` | interactive shells | options, history, keys, completion, plugins, `conf.d/`, prompt |

`PATH` belongs in `.zprofile` because macOS `/etc/zprofile` runs `path_helper`, which reorders anything set earlier.

Load order inside `.zshrc`: options → history → key bindings → completion settings → plugin settings → **antidote plugins** → **`conf.d/*.zsh`** (after the plugins, so my aliases win) → `local.zsh` → Starship.

### Where things live

| Path | Contents |
|---|---|
| `~/.local/state/zsh/history` | shell history |
| `~/.cache/zsh/` | completion dump and cache |
| `~/.config/zsh/.zsh_plugins.zsh` | generated by antidote, do not edit |

## Plugins

Defined in `~/.config/zsh/.zsh_plugins.txt`:

| Plugin | Purpose |
|---|---|
| `mattmc3/ez-compinit` | runs `compinit` once, at the right time |
| `zsh-users/zsh-completions` | extra completions |
| `ohmyzsh/ohmyzsh path:lib/git.zsh` | helpers the git plugin needs |
| `ohmyzsh/ohmyzsh path:plugins/git` | git aliases (`gst`, `gco`, `gp` …) |
| `ohmyzsh/ohmyzsh path:plugins/macos` | Finder helpers (`ofd`, `cdf` …) |
| `zsh-users/zsh-autosuggestions` | grey suggestions from history |
| `zsh-users/zsh-syntax-highlighting` | command highlighting. **Must stay last.** |

Optional tools (loaded only if installed, see `conf.d/30-tools.zsh`): fzf, zoxide, direnv.

## Cheat sheet

### Typing and navigation

| Keys / command | Action |
|---|---|
| **→** or **Ctrl-E** | accept the whole suggestion |
| **Esc f** | accept one word of the suggestion |
| type a prefix + **↑ / ↓** | search history by that prefix |
| **Ctrl-R** | fuzzy history search (fzf) |
| **Tab**, then **Tab** again | complete, then open the menu (case-insensitive) |
| `vim **` + **Tab** / **Ctrl-T** | fuzzy-pick a file (fzf) |
| `projects` (a folder name alone) | `cd` into it |
| `cd -` + **Tab** | pick a recently visited folder |
| `z proj` / `zi` | jump to a frequently used folder (zoxide) |
| a space before a command | the command is not saved to history |
| `fc -li -20` | last 20 commands with timestamps |

### Git (OMZ plugin)

`gst` status · `ga`/`gaa` add · `gcmsg "msg"` commit · `gsw` switch · `gcb` new branch · `gd` diff · `gl` pull · `gp` push · `gpsup` push and set upstream · `glog` graph log

List all of them: `alias | grep "='git"`

### macOS (OMZ plugin)

`ofd` open the current folder in Finder · `cdf` cd to the front Finder window · `pfd` print that Finder folder's path · `showfiles` / `hidefiles` · `quick-look <file>`

### My aliases and functions

| Command | Action |
|---|---|
| `reload` | `exec zsh -l` |
| `zshrc` / `plugins` | edit `.zshrc` / `.zsh_plugins.txt` |
| `paths` | print `PATH`, one entry per line |
| `ll` | `ls -lAhG` |
| `mkcd <dir>` | make a folder and cd into it |
| `zsh-startup` | time startup 5× (target: roughly 50–150 ms) |

## Secrets

Secrets are stored in the **macOS Keychain** and read only when needed. They never appear in files, the repo, or shell history.

```sh
# add or update (-w last = it asks for the value)
security add-generic-password -U -a "$USER" -s OPENAI_API_KEY -w

# pass it to ONE command only (preferred)
with-secrets OPENAI_API_KEY -- python app.py

# export it into the current shell
load-secret OPENAI_API_KEY

# remove it
security delete-generic-password -a "$USER" -s OPENAI_API_KEY
```

Rules:

- Never `chezmoi add` a file that contains a key.
- Keys specific to one project go in that project's `.envrc` (direnv), read from the Keychain. Add `.envrc` to the project's `.gitignore` if needed.
- `with-secrets` runs programs, not aliases or shell functions.
- Apps opened from the Dock don't read zsh files, so they can't see these variables.

## Customizing

| To add… | Put it in | Then run |
|---|---|---|
| an env var for all shells | `~/.zshenv` | `exec zsh -l` |
| a `PATH` folder | `.zprofile` → `path=( … $path)` with `(N-/)` | `exec zsh -l` |
| an alias / function | `conf.d/10-aliases.zsh` / `20-functions.zsh` | `reload` |
| a tool's init line | `conf.d/30-tools.zsh`, guarded by `(( $+commands[tool] ))` | `reload` |
| a plugin | a new line in `.zsh_plugins.txt`, above syntax-highlighting | `reload` |
| settings for this Mac only | `local.zsh` / `local.zprofile` (not in the repo) | `reload` |
| prompt tweaks | `~/.config/starship.toml` | nothing |
| a Homebrew package | `brew install x`, then `brew bundle dump --force --file="$(chezmoi source-path)/Brewfile"` | commit |

Example `PATH` block in `.zprofile`:

```zsh
path=(
  $HOME/.local/bin(N-/)
  $HOME/.cargo/bin(N-/)
  $HOME/go/bin(N-/)
  $path
)
```

`(N-/)` adds a folder only if it exists. Entries listed before `$path` override Homebrew and system commands.

## Daily workflow (chezmoi)

| Task | Command |
|---|---|
| edit a managed file | `chezmoi edit ~/.config/zsh/.zshrc`, then `chezmoi apply` |
| save an edit made directly in `~` | `chezmoi re-add` |
| preview changes | `chezmoi diff` |
| apply | `chezmoi apply` |
| commit and push | `chezmoi cd` → `git commit -am "…" && git push` → `exit` |
| pull updates on another Mac | `chezmoi update` |
| list managed files | `chezmoi managed` |

## Maintenance (about once a month)

```sh
brew upgrade          # tools
antidote update       # plugins
zsh-startup           # speed check
```

After installing any new tool, run `ls ~/.zshrc ~/.zprofile`. zsh ignores these files because `ZDOTDIR` is set, so move any lines an installer added there into the right file in `~/.config/zsh`, then delete them.

## Troubleshooting

| Symptom | Try |
|---|---|
| an error at startup | `zsh -xic exit 2>&1 \| less` |
| need a shell with no config | `zsh -f` |
| `mkdir: /zsh: Read-only file system` | `XDG_STATE_HOME` / `XDG_CACHE_HOME` are missing. Check `~/.zshenv`. |
| a command runs the wrong thing | `whence -va <cmd>` |
| slow startup | uncomment `zmodload zsh/zprof` and `zprof` in `.zshrc` |
| completion acts strangely | `rm ~/.cache/zsh/zcompdump*` then `reload` |
| a plugin is misbehaving | comment out its line in `.zsh_plugins.txt`, then `reload` |
| vi keys instead of emacs keys | make sure `bindkey -e` is in `.zshrc` (zsh picks vi mode when `EDITOR=nvim`) |
